# 🧠 AI & Tech Intelligence Reports (科技与开源 AI 深度研究简报)

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-success?style=flat-square&logo=github)](https://j1nkai.github.io/ai-research-reports/)
[![Design Style](https://img.shields.io/badge/Design%20Style-Japanese%20Cyber--Core-black?style=flat-square)](https://j1nkai.github.io/ai-research-reports/)

> **Project Mission**: 自动追踪并总结全球最新 AI 论文、开源大模型（LLM/VLM）架构演进、Agent 框架及前沿科技动态，生成日式极简 (Japanese Cyber-Core) 风格的深度研究 HTML 报告。

---

## 🏛️ 核心亮点 (Key Features)

- **日式极简 Cyber-Core 设计**：结合纯白/暗黑双色调与高密度前沿科技情报排版，去模板化（Anti-slop）。
- **结构化提炼**：对 AI/LLM 领域的论文、框架、算法突破进行纯中文深度总结与核心技术点提炼。
- **全自动发布**：定时通过自动化流水线更新报告并推送到 GitHub Pages 部署。
